# Bobby Docs

The reference for Bobby. Hosted at docs.bobby.[tld].

## Working on this

This repo is a Docusaurus 3 site. Edit content as MDX in `docs/`. The site rebuilds and deploys on push to `main`.

## Local dev

```
npm install
npm run start
```

Site runs at `http://localhost:3000`.

## Structure

- `docs/` — the page MDX files, organized by section.
- `src/components/` — custom React components (Convergence Engine, League Leaderboard, Proof Ticker, surface mocks).
- `src/css/custom.css` — brand tokens and theme.
- `static/img/` — logos and image assets.
- `docusaurus.config.js` — site config.
- `sidebars.js` — navigation tree.
