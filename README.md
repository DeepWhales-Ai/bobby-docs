# Bobby Docs

The reference for Bobby. Hosted at docs.bobby.[tld].

## Working on this

This repo is a Mintlify project. Edit content as MDX. Mintlify rebuilds on push to main.

## Structure

- `docs.json` — navigation, theme, metadata.
- MDX pages live at the repo root, organized by route (`groups/`, `projects/`, `community/`, `intelligence/`, `surfaces/`, `brand/`, plus `index.mdx`, `start.mdx`, `links.mdx`).
- `images/` — logo and assets referenced from `docs.json`.
