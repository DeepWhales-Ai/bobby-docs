title: "Commands"
description: "Every Bobby command. Type them in your group, or in DM where noted."
---

| Command | What it does | Who can run it |
|---|---|---|
| `/add` | Start the add wizard. Auto-detects chain, ticker, listing. | DM only |
| `/set_portal` | Set where the portal button on alerts links. | Group admin |
| `/set_socials` | Register your project socials. X, TG, web, dexscreener. | Group admin |
| `/alerts` | Tune threshold, quiet hours, format, categories. | Group admin |
| `/info` | Render the info panel. Socials, ticker, chain. | Anyone |
| `/scan` | Bobby returns what he sees on the token, plain language. | Anyone |
| `/why` | Why Bobby pinged. The story behind the last alert. | Anyone |
| `/quiet` | Toggle quiet hours on or off for this group. | Group admin |
| `/portal` | Tap-through portal link. | Anyone |
| `/socials` | Render the registered socials. | Anyone |
| `/help` | Bobby's command list, in Bobby's voice. | Anyone |
| `/support` | Open a support ticket. Routes to a human. | Anyone |

<Tip>
**Prefer slash menus.** On most Telegram clients, typing `/` in a group with Bobby brings up a menu. You do not need to memorize a thing.
</Tip>

## Aliases

Bobby honors short forms where they are unambiguous. `/i` for `/info`. `/s` for `/scan`. If a short form would collide with another bot in your group, type the long form.
