Every command lives here. Type them in your group, or in DM where noted. On most Telegram clients, typing `/` brings up a menu, so you do not need to memorize a thing.

## Group admin

| Command | What it does |
|---|---|
| `/add` | Start the add wizard in DM. Auto detects chain, ticker, listing. |
| `/settings` | Pick which group you are configuring. Admin only. |
| `/customise` | Toggle what Bobby posts: booster post, league post, broadcasts, Bobby AI. |

## Socials and portal

| Command | What it does |
|---|---|
| `/set_portal {url}` | Set where the portal button on alerts links. |
| `/set_main {url}` | Set the main link for the project. |
| `/set_x {handle or url}` | Register the project X account. |
| `/set_website {url}` | Register the project website. |
| `/set_socials` | Register everything in one command. |
| `/show_socials` | Show what is currently registered. |
| `/socials` | Render the registered socials in chat. |

## Syntax rules

- **Groups auto fill.** In a group, token commands use the group's registered tokens. If more than one is registered, Bobby shows a picker.
- **DM takes the address.** In DM, `/buy` and `/ca` accept a full contract address.
- **Addresses are always full.** Bobby never shortens a contract address. If it is shown, it is shown whole.

## Only speaks when it matters

Members read Bobby because Bobby only speaks when it matters. We keep it that way.

You cannot tune the methodology. You cannot weight a single source. You cannot turn detection into a firehose. Those are not settings. The internal joke is twelve herbs and spices.

## Permissions Bobby needs

| Permission | Required? | Why |
|---|---|---|
| Send messages | Required | Bobby needs to be able to ping. |
| Pin messages | Optional | For the welcome pin and major convergence alerts. |
| Delete | Never asked for | Bobby does not moderate. |
| Admin | Required | Bobby needs admin to read group activity and post alerts. He never moderates members or deletes content. |

Bobby is admin permissioned, not a moderator. The admin role is the floor Telegram requires for Bobby to do his job.
