## Badges on a row

- **Verified ✓.** The project passed Bobby Founders qualification. The check is editorial, not paid.
- **Trending.** The row appears on The Board right now. The badge surfaces in buy alerts elsewhere on the network too.
- **Epic tier.** The row crossed an Epic threshold (500+ boosts, 1000% from entry, $1M+ daily volume while trending, holding #1 for an extended run).
- **New entry.** First appearance on The Board this week.

## How a tap moves it

A user in any Bobby group taps the BOOST button on a buy alert. The token's boost count increments. The Board re-ranks on the next refresh. The League scores the user and the group. One action. Three surfaces.

One tap. Free. The verb the network runs on. Every buy alert across every Bobby group has a BOOST button. Tapping it pushes the token up The Board and counts toward The League. No payment. No threshold. No gate. **Boosted tokens trend first.**
